## 多尺寸支援

- `gridRows`/`gridCols` 為變數,`setGridSize(rows, cols, preserve)` 重建網格;工具列「地圖尺寸」下拉**五鎮各自一個選項**(依城鎮順序:健康/東部/湖畔/溪谷/百靈;value 帶 `-城鎮` 後綴以區分同尺寸城鎮)。
- `PRESETS` 每鎮帶 `rows`/`cols`;`data: null` 的城鎮選取後以正確尺寸開空白畫布。
- 分享碼:非 26×24 時帶 `RxC;` 前綴;**26×24 維持無前綴,舊連結與外部產生器完全相容**。`decodeMap` 依前綴解碼,`importGridData` 依陣列尺寸自動切換畫布。
- 座標軸:X = r+2、Y = gridCols+1−c(各鎮皆從 [2,2] 起算,與實機一致)。
- `scripts/check.js` 驗證各內建圖尺寸(MAP_SIZES)、26×26 前綴格式往返與「26×24 無前綴」守護檢查。

## east.json

使用者實機手繪抄錄的東部小鎮開局地形(2026-07 定稿),26×26,座標 [2,2]–[27,27]。
(手繪時畫布多出的最左欄與最底列已於收錄時裁掉。)
與 `sim/index.html` 的 `PRESET_EAST_DATA` 內容一致(單行字串、無 bid,
匯入時由 `assignBlockIds()` 自動補回多格建築的 bid);改地形時兩處要同步,
並跑 `node scripts/check.js`。
